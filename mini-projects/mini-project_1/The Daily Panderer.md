**The Daily Panderer**

**Nolan Ramón Barton-Gómez**

**CART 351 \- Mini-Project 1**

For the first mini-project, I created a satirical ‘news’ website that reinforces any claim the user makes called ‘The Daily Panderer’. I wanted to do something that followed themes of misinformation and bot farms. At first, I was looking for ways to incorporate real data, but I settled on making something a bit more humorous. When the user opens the web page, they are greeted with what looks like an ‘InfoWars’ style ‘news’ website. There are absurd alarmist messages on the top scrolling horizontally in the style of a news marquee saying things such as ‘The Children: Save Them\! Now\!’. Below the header, there is a box for the user to submit any claim they want. When the user submits their claim by hitting the ‘amplify’ button, 40 ‘accounts’ appear across the map mirroring the claim in different terms. There is a button called source which is used to ‘verify the source’ of the claim: the user. The user can reset the map at any time. 

The website is made using p5, flask and python with CSS used to make the application look like a tabloid. P5 is used to send the claim to the server, then animate the arrival of the bots. Flask receives the claim, generates the bots in Python, saves the swarms to a json file and returns it. Until the user hits reset, all the swarms accumulate and stay on the map. A python file called bots ensures a degree of variance by generating fake handles, locations and a rewritten version of the original claim using synonym swaps, capitals, emojis and typos. The flask techniques from the project requirements are used. Fetch POST to send input, JSON storage on the server and fetch GET to display the result. I used the land-110 topoJSON file to create the map and ensure that the accounts would not be sending them from the depths of the ocean. 

The basic setup was not too difficult, and I was quickly able to create slight variations of the input phrase. However, I wanted more variation, and the application didn’t have a map yet, it just animated clusters on a blank canvas. I thought that giving these voices a location would add an extra dimension to the project. I learned about topoJSON files, and I tried very hard to incorporate this into the canvas on my own, but I simply hit a wall. I could not get the functions right and I would always end up with a black screen or claims without a map. Eventually, I gave up and used Claude to find out what was wrong. It turns out I accidentally messed up the order, setup() was happening before the map existed. So I would get the ‘claims’ before the map. The correct order of course is having the swarms be built last. I had also accidentally defined windowResized twice. After I fixed the bugs, I wanted more variation in the messages so I used claude again to help me expand my synonym lists and word pairs to make the effect a bit more colourful. The grammar is pretty broken on many of the messages, but to me this is perfectly reminiscent of what you might see in the comments of a Facebook post. I played with the username base words to have some funny results and that was it. 

The texts we had to read made me think about misinformation and bots more than anything, and how much internet traffic is manufactured. We instinctively trust things like virality and location data and are manipulated by false patterns. Data is not neutral and it is carefully manicured to mislead people.

The most challenging part of this project for me by far was incorporating the topoJSON file and drawing my map for the claims. I spent a lot of time on this alone and eventually had to use the dark arts to get me out of my rut. Overall, I like the result. It makes me chuckle. Some things I would add to a future iteration would be fake ad placements.
