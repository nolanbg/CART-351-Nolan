Week 1


This week, we looked over how data moves through the web. The lecture included concepts like client-server requests, IP addresses and packet transmissions through TCP/IP. This was followed by a demonstration of a dynamic web application to elucidate and expand on the terminology. While going through the Read and Explore page, I noticed a small typo in your first <p>, you wrote ‘They are not specifically for CART 263’. Some of the readings and example sites were familiar to me from my previous years in the CART program, although the AI section was mostly new to me. I am excited by the idea of creating web projects with an emphasis on networks and creatively linking different technologies together, and not so much on immaculately clean code(although I’ll do what I can). I am particularly eager to be using Python, because my favourite artistic software is TouchDesigner which relies on it. I have dabbled with Python scripting in TouchDesigner, but I would be excited if I could find a way to develop this into a project.




Week 2


This week, we went over the basics of Python. First, we went over Python’s versatility and reasons for its popularity. Python is popular for its varied use cases, vast community libraries, and high level of abstraction which makes it closer to English. I had already installed conda and set up my interpreter before class so I spent a bit of time waiting. Then we started defining variables and doing basic commands in the terminal. We looked at operations, how to comment and the basics of functions and syntax. It seemed familiar to me from my minor Python experience in TouchDesigner, so when we got the opportunity to begin the exercise I got to work. I did not realize only the first part was due for the next class, and I finished all the questions. I did not have any major issues with the homework, but I wasn’t sure how to present the exercise on my github web page. I decided in the end to create a folder with the actual python file, but also just display the code on the ‘exercises’ html page I made. I put a <br> after every line so it would be legible and possible to copy into the terminal to run. I was unsure of how to go about running a Python file through an html web page, but I would like to learn if it is possible.




Week 3


This week, we continued looking at Python concepts. We started by going through methods of organizing, slicing and joining lists as well as how to use Python in conjunction with a text file. We ran into a small hiccup due to what I believe was a link at the start of the file. After this part of the lecture we moved on to dictionaries, including their organization by ‘keys’ and their associated values. Finally, in the most interesting part of the lecture, we talked about APIs and did some small experiments with the weather API. I have some experience using APIs in other classes and they are often very powerful tools to use in projects. All parts of the lecture made sense to learn about in a single class, because lists and dictionaries become very useful when using APIs. APIs can help us access a wealth of data, but the real work is often sifting through and organizing this data to find the parts that are relevant to our particular project.
